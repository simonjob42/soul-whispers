# 心语卡片 · Soul-Whispers

温暖治愈的每日感恩与灵感便签墙（支持中英文双语、夜间护眼模式、云端账号同步、管理员后台、PNG 卡片导出与手机 PWA 安装）。

- **在线访问（Render 全栈版）**：https://soul-whispers.onrender.com
- **管理员后台**：https://soul-whispers.onrender.com/admin.html
- **源码 ZIP 下载**：https://github.com/simonjob42/soul-whispers/archive/refs/heads/main.zip

## 手机安装为 App
1. 用手机浏览器打开 https://soul-whispers.onrender.com
2. **iPhone (Safari)**：点击底部「分享」→「添加到主屏幕」
3. **Android (Chrome / Edge)**：点击页面顶部「安装 App」按钮或浏览器菜单「安装应用」
